# 独立候选验收启动器

只用于包含 S1 启动隔离的后续独立解压候选，不用于已公开 beta.1 或安装器。此脚本不安装、不复制、不覆盖程序，不修改快捷方式、注册表或系统环境；测试电脑无需 Git、Node 或 npm。

先按交付清单核对固定候选及此脚本的哈希。用 Windows PowerShell 指定候选内 `Asterium.exe` 的绝对路径、验收批次和独立端口。示例中的占位须替换；先仅检查：

```powershell
.\Start-AsteriumAcceptance.ps1 -ExecutablePath '<独立解压候选>\Asterium.exe' -Batch 'r1' -Port 17363 -DryRun
```

核对 JSON 回执中的候选 SHA-256、profile、批次、端口、资料路径和参数后，去掉 `-DryRun` 才启动。默认资料是 `%LOCALAPPDATA%\Asterium-Test\<批次>`；重启同一批次沿用目录，新一轮使用新的批次名。可用 `-DataDirectory '<独立绝对路径>'` 明确指定资料位置；已有无标记非空目录、其他环境目录及目录链接会拒绝，不自动清空、复制或迁移。

默认不恢复后台服务。只有本轮确需测试时显式追加 `-BackgroundServices`。端口占用由产品明确报错，不连接另一实例或自动换端口。关闭窗口可能仍在托盘，结束本轮请使用托盘“退出星丛”；脚本不杀进程，不清理验收资料，不执行卸载。回执中的进程号表示启动请求，不证明产品已通过启动检查或验收。

启动器仅为后续固定验收包的源码工具，本阶段不生成、安装或发布候选。程序、脚本版本和每轮原始证据分别保存；不得拿旧候选代替包含 S1/S2 的新候选。

脚本在自身进程中显式加载当前 `$PSHOME` 下已有的 Microsoft.PowerShell.Utility，避免父进程继承的模块路径选中其他版本。没有安装模块、升级 PowerShell 或修改系统配置；候选始终通过 Get-FileHash 的 SHA-256 计算生成回执，加载或计算失败即停止，不跳过校验。
