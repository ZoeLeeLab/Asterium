# 星丛子代理任务阶段核验

## Codex 执行入口更新

按用户后续决定，Codex 已加入执行伙伴候选名单，可接收文本和指定的 PNG、JPEG。执行复用目标伙伴选定的本机 CLI，在临时目录运行一次性任务。Codex 发起的批次也可在后台自动汇总。候选能力标记为宿主读取权限，任务目录外的强制拒读留待后续验收。

本次以合成 CLI 事件验证图片参数、任务提示、输出解析和工具配置。真实模型读图仍需指定测试连接。下方阶段记录保留先前关闭 Codex 入口时的实现和验收结果。

本轮在发布版工作区实现单聊派单。已有头像和记忆兜底改动保留，沿用其独立验收记录。当前源码包含 API、本地 Codex 和 Claude 单聊的工具接入，任务执行者可使用 API 图文连接或官方 Claude CLI 文本连接。Codex 动态工具随新线程注册，已有线程继续使用其原生工具清单。

Main 按活动轮次绑定任务，使用每轮三项、每环境三个槽、每个执行伙伴一个槽的持久队列。普通会话在可选的两分钟等待期间可通过新文本消息打断，后台执行期限从任务实际开始计为 30 分钟。任务卡显示结果与原始回复，API 或 Claude 发起伙伴的后台汇总通过会话租约安排，并显示在来源任务卡内。Codex 发起伙伴可以在当前轮等待和汇总，后台分支结果通过任务卡查看。

附件按原消息发送记录和 SHA-256 绑定。API 图片能力、连接指纹及资料在运行时重新核对。首版 Claude 目标只接收文本及文本文件。真实 API、Claude 模型和 CLI 版本验收需使用指定测试连接。

## 本地 Codex 执行边界

已知 Codex CLI 0.144.5 的只读探针可读取任务外的四类合成诱饵。本轮检查已有星丛沙箱 helper 的宿主状态，发现测试宿主未通过现有沙箱预检。现有 AppContainer 预检会在权限及 ACL 变更前拒绝该宿主，因此当前无法运行同边界的正常图文和任务外拒读验收。Codex 目标排除在候选与执行名单外。

后续应使用普通权限测试宿主，先验证正常图文路径，再验证任务外诱饵、模拟源码、模拟记忆和其他会话附件在绝对路径、父路径及目录链接下的实际拒读。需要修改隔离机制时，先根据测试结果决定范围。

## 回归结果

- `npx vitest run --maxWorkers=4 --testTimeout=15000` 通过 214 个文件、1691 项测试，保留 2 个既有 TODO。15 秒为本次运行参数，能力词典的真实检查约 6.16 秒。
- typecheck、lint、16 条能力词典检查和 `git diff --check` 通过。
- 初次全套回归发现普通中途消息的暂存被异步等待查询推迟。恢复同步暂存，只有 Main 确认打断委派等待时才转为延迟发送。
- 新增工具接入用例的首次断言遗漏了附件数组的 schema 默认值，校正断言后通过。
- 本次验证包含合成任务、既有模拟 UI 和协议回归。真实图片理解、Claude CLI 委派及 Codex 硬隔离仍需指定测试环境验收。
