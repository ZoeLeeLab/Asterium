# 0.1.0-beta.1 本地 r3 候选准备

本轮在已保留的 r2 之后建立新候选，不覆盖旧包、哈希、原始失败或人工验收。仍为未签名 Windows x64 Beta，不创建 Release、不上传、不 push，不执行安装器或覆盖用户资料。

首轮 r3 的发布前检查全部通过，但应用打包因 Windows 把自有 `LICENSES` 与第三方 `licenses` 识别为同一路径而失败，未生成安装包。修复仅将自有 CC BY 全文作为独立文件交付到资源根目录，源码布局和原文不变。失败尝试保留；新候选重新核验并使用独立目录，不把失败中间文件交付。

## 源码改动

- 公开更新源绑定为 `ZoeLeeLab/Asterium`。维护者手动创建的仓库经匿名只读检查为公开空仓库，分支和 Release 均为空。客户端可检查公开列表；没有发行版本时不提供下载或安装。真实资产下载、升级和资料保留仍待验收。
- 本候选纳入 [许可收尾及安装器调整](0.1.0-beta.1-r3-licensing.md)：自有代码 MPL-2.0、素材范围、品牌及致谢、第三方原文、固定源码配套，以及替换 WinShell 的 Windows COM 实现。旧候选不自动获得这些更改。
- 保持 Codex、Claude CLI、审批、伙伴身份和业务数据实现；不新增登录、权限架构、沙箱或真实服务连接。

## 核验与停止边界

更新源的 20 项针对性测试已在本地通过；完整发布前检查、固定提交的应用/安装器构建及产物审计以本轮新收据为准，未执行内容不记为通过。代码提交存在后，再以纯文档提交记录桌面能力的真实核验基线；其余条目保留真实引用。

更新源代码提交为 `7a1f2f3c69eabdd6c20bf220b22ee9a10f8132c6`；桌面验收脚本对已配置地址的调整依次保留在 `974ad2f61931243e02bbfa17b37419de8275e99c` 和 `bee7e4bfc1a3076b42cdeb69868552b748879d73`。此纯文档核验绑定最后一笔已存在代码基线，不重写历史；打包后的实际脚本执行仍待新包生成。

最终文件名、大小、SHA-256、完整源码提交、完整可达 Git 历史审计、原始日志及待办在仓库外的本轮交付目录保存。自动检查与解包核验不代替普通账户安装、快捷方式真实固定项、升级/卸载重装、真实模型与核心协作验收。通过检查也不自动触发公开发布。
