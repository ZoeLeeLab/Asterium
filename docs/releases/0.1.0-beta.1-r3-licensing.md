# 0.1.0-beta.1 许可收尾与安装器调整（待新候选核验）

## 变更

- 自有客户端代码采用未改写的 MPL-2.0；维护者批准自有文档、默认头像和主题图使用 CC BY 4.0，Logo 单独列品牌范围。版权署名 ZoeLeeLab，致谢为“小Co&小川（Codex）”。第三方原许可不被项目许可覆盖。
- 关于页显示实际许可与版权，并按需读取随包的许可、范围、品牌和致谢全文；首页仍保持简短，不增加常驻长文。
- 补 ELK 0.9.3 对应的 Java 基线/上游补丁，以及 GWT、Guava/Guava-GWT、EMF-GWT 和 Xtext 的原始版权与许可。版本、源码哈希和原始文本块可检查，不声称完成逐字节重建或精确二进制 SBOM。
- nsis7z 保留上游未指定版本的 LGPL 声明，明确选择遵守 LGPL-2.1，并补 NSIS API 的 zlib/libpng 原始文件头。LZMA SDK 的公有领域声明单列；分发时仍须落实对应源码材料。
- MouseCrew 继续按 MIT 保留。工作室阶段加载与原生工作流方法的实际用途、固定修订和署名分别说明；九项原始文件恢复为上游字节，变化仅为早期导入的末尾空白。
- StdUtils 配套源码排除两个上游打包工具和两项 IDE 文件，90 个保留文件的字节不变；必要的三个 `.lib` 构建输入仍保留并明确标注。原归档与整理后归档分别记哈希，原始证据不覆盖。补充内嵌 RHash、BLAKE2 和 NSIS 接口声明；整理归档不是逐字节复现插件的证明。
- 安装器模板按版本与文件哈希核验，只在新构建目录替换 WinShell 的三类调用，使用原生 Windows COM 和现有 System 插件。保持 Beta 身份、当前用户安装、快捷方式偏好、完成页默认不启动及资料保留；没有新增运行时服务、端口或权限架构。
