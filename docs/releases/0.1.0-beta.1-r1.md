# 0.1.0-beta.1 / r1 候选说明

状态：本地候选准备中；未公开发布，未签名，普通账户安装及真实订阅功能待验收。本文件不继承旧 0.1.0 候选的验收结论。

## 范围

- Codex 接入和认证保持现状。
- Claude 由 Agent SDK 替换为用户另行安装的未修改官方 CLI；不新增登录、不引入 API 替代、不自动更新 CLI。保留伙伴标识、业务服务、事件与会话数据。MCP 使用 stdio，经当前账户和 CLI 进程树绑定的本机命名管道回到主进程，未增加产品 HTTP 监听。
- 主审批和路径校验负责权限边界；Hooks 仅作额外防线。官方版本号不构成安全保证，已知 Windows Hook 故障仍须在主审批拒绝下阻断操作。
- 版号统一为 0.1.0-beta.1，Beta 安装标识及默认资料独立，卸载保留资料；增加桌面快捷方式选择和完成页启动选择。
- 打包脚本随源码维护，冻结提交导出后构建；产物名含提交短号，源码、缓存和证据集中在指定交付目录。

开发机的官方 CLI 加本地合成服务验证不等于会员订阅或真实模型通过。CLI 仅列实际通过的版本与 Windows 环境；不推断更高版本安全。资料重读、记忆、工作室、交接、压缩与日记等自动覆盖范围以测试明细为准，真实用户流程仍待验收。
