## 本候选构建与安装行为

- 从构建对应提交导出源码，逐个校验导出文件与 Git blob 一致，再构建应用。
- 安装器仅面向当前用户，使用独立候选名称、安装标识与开始菜单名称，不要求提权。
- 本候选不创建桌面快捷方式，没有安装完成后选择是否立即打开的选项，安装后不自动启动。
- 配置为卸载时保留用户数据。此项是安装器配置事实，卸载重装与数据保留的人工验收仍待完成。
- 安装标识独立不代表应用默认数据目录独立。曾使用星丛的 Windows 账户可能继续显示该账户原有资料；隔离方法见 [数据目录与隔离验收](../data-isolation.md)。
- 安装器已解包，其中 90 个应用文件与已审计应用逐字节一致。内容扫描未发现私人路径、测试角色、演示数据或凭据。
- 扫描命中已逐项复核，其中第三方压缩代码的标识符误报与相关 SDK 文件一致性核对记录另存，没有未解决的私人信息命中。
