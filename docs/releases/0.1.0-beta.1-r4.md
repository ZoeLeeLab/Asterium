# 0.1.0-beta.1 本地 r4 候选准备

版本仍为未签名 Windows x64 Beta，r4 是本地候选编号。旧 r3 包、源码、失败尝试和验收证据保持原样；不自动安装、不迁移或覆盖用户资料，不上传、不 push、不创建 GitHub Release。

## 修改

- 缩略图改为从已授权附件快照读取字节，不再依赖 Windows Shell 对无扩展名 preview/content 文件取缩略图。PNG/JPEG 按比例限制在 960×720 内，小图不放大；不支持或损坏的图片回退图标，实际缺失/超限仍拒绝。
- 卡片状态按会话和附件 ID 隔离。缩略图失败不再把有效快照标为丢失；修复状态更新取消自身请求的时序问题。读取、预览和发送仍由既有主进程存储及权限检查控制，不改变快照格式。
- 新建模型和快速切换到新模型时默认开启图片；已保存模型的明确关闭保留，旧 DeepSeek 适配器维持当前限制。schema 对旧缺省字段及迁移的行为不变，不自动开启用户已有连接。
- Codex、Claude CLI、认证、命令审批、安装身份、资料目录及两项安装选项保持现有实现。
