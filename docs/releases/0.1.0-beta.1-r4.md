# 0.1.0-beta.1 本地 r4 候选准备

版本仍为未签名 Windows x64 Beta，r4 是本地候选编号。旧 r3 包、源码、失败尝试和验收证据保持原样；不自动安装、不迁移或覆盖用户资料，不上传、不 push、不创建 GitHub Release。

## 修改

- 缩略图改为从已授权附件快照读取字节，不再依赖 Windows Shell 对无扩展名 preview/content 文件取缩略图。PNG/JPEG 按比例限制在 960×720 内，小图不放大；不支持或损坏的图片回退图标，实际缺失/超限仍拒绝。
- 卡片状态按会话和附件 ID 隔离。缩略图失败不再把有效快照标为丢失；修复状态更新取消自身请求的时序问题。读取、预览和发送仍由既有主进程存储及权限检查控制，不改变快照格式。
- 新建模型和快速切换到新模型时默认开启图片；已保存模型的明确关闭保留，旧 DeepSeek 适配器维持当前限制。schema 对旧缺省字段及迁移的行为不变，不自动开启用户已有连接。
- Codex、Claude CLI、认证、命令审批、安装身份、资料目录及两项安装选项保持现有实现。

## 现有验证与本轮归属

修复工作区已通过 209 个测试文件、1636 项测试、0 失败、2 项既有 TODO；另有 95 项专项及 9 项真实 Electron 合成图片用例通过。合成 PNG 在旧 Shell 接口下带扩展名成功、无扩展名复现原报错；新解码路径通过，WebP/GIF 实测为图标降级，不声称缩略图支持。

维护者反馈本次开发版人工验收无问题。没有单独采集每一步的原始人工证据，因此不扩大解释为所有服务、所有图片或新安装包已验收。API Key、真实连接及用户验收目录不纳入测试和构建，使用合成图片及模拟服务。

后续提交与发布前检查、从最终冻结提交导出的应用/安装器构建、完整可达 Git 历史及产物审计分别记录新收据。代码提交存在后，再以纯文档提交绑定受影响的两条能力记录；其余保留真实引用。最终文件路径、大小、SHA-256 和来源在本轮独立交付报告中，不写未来 SHA、不转移旧包验收。

## 待验收

普通账户的新包空白启动、设置保存、图片附件、两个安装选项、升级/卸载重装保留资料以及真实伙伴协作仍须对新候选核验。公开仓库目前为空，实际更新资产下载与升级待未来更高版本发布后验证。未签名可能触发 Windows 提示；通过自动检查不自动触发公开发布。
