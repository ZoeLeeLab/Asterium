# 星丛 Asterium Beta.8 · Windows x64

## 本次更新

- 改善长 Codex 单聊重新获得焦点时的输入和发送响应，减少重复整理未变化的历史消息，并批量处理运行状态更新。
- 减轻启动时读取长会话对主进程的阻塞。新增独立的星形启动小窗，主界面就绪后立即进入，不等待动画播完，也不先显示空白主题背景；加载失败时可重试或退出。
- 委派结果会持久保存并送回发起任务的原对话，可跨轮查看。伙伴可在空闲时接着结果向用户汇报，用户消息优先处理；内部回传资料在聊天历史、搜索和定位中隐藏。
- 委派任务可携带 read／write 的任务提示。实际可执行范围仍由接收端原有权限决定，这不是新的执行层沙箱或额外授权。
- 可对伙伴回复中的已交付本机文件链接使用右键菜单，打开所在文件夹、复制路径、另存为或保存到项目。
- 修复单聊左栏滚动条挤压内容、角色对话列表偶发无法收起，以及导入记忆没有标签的问题。
- 修复用户消息中 Markdown 段落、列表和显式换行产生的异常空隙，保留消息原文、代码格式及既有链接交互。
- 按领域整理主进程 IPC 与运行服务，保留已有接口、历史格式和旧运行分支。

## 安装与更新

下载 Windows x64、文件名以 `-setup.exe` 结尾的安装器。覆盖安装前请从托盘完全退出星丛，选择原安装目录。已有 Beta 用户可在「关于」中开启「接收测试版更新」，再检查更新。

安装器为未签名的 Beta。请从本仓库发行页下载，并核对附件 `SHA256SUMS.txt`。发行附件同时提供与安装包构建提交对应的源码及第三方源码材料。

启动优化针对正常索引读取；首次历史迁移或异常索引恢复仍可能需要等待。启动小窗不设置最短播放时间，打开很快时可能只短暂出现。
