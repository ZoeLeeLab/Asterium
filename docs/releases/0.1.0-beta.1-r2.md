# 0.1.0-beta.1 首版补齐候选（r2）

本轮在已有本地 Beta 候选后补齐群聊附件、用户控制的客户端更新，并按维护者提供的布局参考精简关于页。产品版本仍为 0.1.0-beta.1，以新源码提交和安装器文件名区分本地候选；旧包、哈希与原验收记录保持原样。

## 变更

- 群聊可选择图片/文件，支持附件单独发送、消息卡片预览、快照持久化与伙伴读取；复用单聊存储和适配器，新增主进程群聊账本到原生会话的附件关联，不改变 CLI 接入或认证。
- 关于页缩为 Logo、一句定位、实际版本、更新状态、紧凑发行信息及折叠的第三方声明；不再重复 README 的长篇介绍。
- 客户端更新采用公开 GitHub Releases，检查、下载和安装分别由状态与用户动作控制；新增进度、取消、大小/SHA-256 校验及安装前复核。启动检查及测试版偏好保存到现有通用设置。
- 公开仓库地址仍待绑定，未创建远端或上传。当前候选明确显示未配置，不把模拟更新写成真实升级验收；详细约定见 [客户端更新](../client-updates.md)。

## 边界与待验收

群聊不同伙伴的文件能力及外部线程限制见 [群聊附件](../studio-attachments.md)。Codex 适配与认证保持不变；没有新增 Claude 登录、沙箱或权限架构。项目许可证、代码签名及剩余第三方许可问题维持原状态。

旧候选的本机空白启动、设置保存及 Claude 对话反馈记录在 [关于页补齐记录](0.1.0-beta.1-about-fix.md)。它们不自动转移到此候选；新包需再次验证这些项目，以及群聊附件、更新设置和安装选项。真实 GitHub 更新与升级安装待公开源绑定后单独验收。

构建提交、全套检查数量、失败/跳过/TODO、安装器大小及 SHA-256 以此次冻结构建的独立交付报告为准。未冻结前不填写未来提交或虚构结果。不创建 GitHub Release，不上传，不 push，不自动安装。
