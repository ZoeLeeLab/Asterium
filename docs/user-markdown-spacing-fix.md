# 用户消息 Markdown 间距修复

基线：`397da50fe928379ece26e463f5298c4a3c1a7e04`。

用户气泡用 `white-space: pre-wrap` 保留输入换行。Markdown 转成 HTML 时，在块元素之间及显式换行元素之后插入的排版换行也因此变成可见空行，叠加段落和列表本身的间距。普通文字的行高配置没有改变。

修复仅在用户消息的 Markdown 渲染阶段移除这些结构换行，不改原始消息、存储、全局样式或伙伴回复。保留段落内手动换行、连续空格、列表内行内元素之间的换行、代码缩进和空行。单聊和工作室复用同一实现；工作室引用、提及及链接处理保持原行为。
