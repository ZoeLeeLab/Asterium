## Claude 接入与后续产品方向

保留 `@anthropic-ai/claude-agent-sdk` 0.3.281 自身的保留权利声明，不称其为 MPL 或自由开源 SDK。当前存在 SDK 随包交付、指向外部 CLI 的具体实现，需要核实 SDK 再分发与认证链路，不能仅凭 CLI 能登录就宣称星丛的 SDK 使用已获许可。

核对 [Anthropic 官方法律与合规说明](https://code.claude.com/docs/en/legal-and-compliance)：第三方产品 / Agent SDK 应使用 API key 或受支持云服务；不允许第三方应用提供 Claude.ai 登录或替用户转用个人订阅凭据。用户在未修改的官方 CLI 中通过官方流程登录，属于页面另行描述的原生 CLI 场景。**不收集账号密码、Cookie、会话或订阅 OAuth token；订阅付费本身不等于第三方 OAuth 授权。** 本轮未读取或测试私人凭据。

维护者最新方向：若 Claude 不允许所需接入方式，后续可以只做 Codex。本文已记录为方案偏好，尚未删 Claude 功能或实现新 OAuth；Codex 的具体第三方登录 / 分发许可另行核实，未在此宣布允许。真实实现与许可确认之后，再同步功能文档和能力条目。
