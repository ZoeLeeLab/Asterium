# 隐私与发布检查

测试夹具、文档里的示例、配置样例、截图、录屏和发布材料只能使用明确的合成数据。禁止复制真实昵称、私人对话、真实线程或会话 ID、本机或服务器路径、真实连接域名、账号和凭证。使用示例角色、固定合成 UUID、通用路径及保留示例域名。录制画面时从干净的隔离资料启动，并逐张检查可见内容和元数据。

正式项目链接、公开许可与署名、官方协议参考是公开资料。必须匹配生产地址或固定协议格式的测试，只使用脚本中明确列出的公开端点和合成主机，并通过模拟服务或测试配置运行。实际连接和验收原件留在私有环境。

## 提交与发布

- 提交前执行 `npm run check:privacy`。暂存后执行 `npm run check:privacy -- --staged`，复核暂存 diff。未解决的发现必须修正后再提交。
- 发布前执行 `npm run check:privacy -- --commit <冻结提交的完整 SHA>`。候选构建入口在应用和安装器两个阶段都会实际扫描冻结提交，源码检查收据必须包含真实的 `privacy` 成功记录。
- 用 `npm run check:privacy -- --materials <独立发布材料目录>` 扫描准备公开的发行说明、示例、截图和其他非打包材料。目录只放拟公开材料。安装器和源码包仍按候选流程解包检查，分别校验清单、内容和摘要。发布前另外检查此次将公开的新增 Git 历史，防止敏感值藏在中间提交。
- 图片和其他受管媒体由 `scripts/privacy-media.json` 记录人工检查通过的路径与 SHA-256。外部发布材料使用 `materials/` 加目录内相对路径作为键。任何新增或变更媒体都需要检查画面和元数据后更新记录。

脚本检查已知称呼和凭证模式、疑似本机路径、未批准域名、账户邮件、真实形态的 UUID 或线程 ID、敏感文件类型以及未经登记的媒体。诊断只显示文件、行号和类别。任意私人叙述、陌生昵称、图中文字及隐蔽凭证仍须人工复核。现有公开版本与历史提交保留原归属。
