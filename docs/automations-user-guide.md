# 自动化使用与人工验收

## 可以使用的范围

设置 → 自动化，或单聊／工作室顶部的时钟按钮进入。自由填写任务，也可选择项目日报、文件整理、条件巡检模板并编辑。支持一次、每天、每周、固定间隔（至少一分钟）；模型任务只在星丛运行时执行。

侧栏也有入口：单聊在“插件”下方是“自动化”；工作室在“新建项目”下方依次为“插件／自动化”。插件可进入 MCP 和 Skills 管理，自动化会带入当前单聊或群聊。

先与目标伙伴完成一次对话，建立准确原线程，再选择该对话。API 伙伴和本地伙伴复用既有运行器、线程、目录与审批。改动目录授权、原线程或绑定后，旧任务暂停在排队／待重新绑定，不自动切换目录或新建线程；编辑任务重新选择目标。

外部伙伴可以在用户单独允许后，通过 MCP 管理自己的任务，但定时执行仍需要 CyberBoss 专用 Adapter。现阶段目标会标记待就绪，不会走普通用户消息或微信通道。接入合同见 [外部 Adapter](automation-adapter-contract.md)。

## 补执行与运行记录

- 每天／每周：原本已存在的任务，当天错过时可在星丛打开后补一次。只补今天，不追补多天。下午新建“每天十点”的任务从明天开始；可单独点立即运行。
- 一次：指定未来时间，离线错过后下次打开补一次。固定间隔错过多轮只合并最近一轮。
- 暂停取消尚未开始的排队及以后计划；当前轮次继续，需另外点取消本次。恢复从下一计划时刻开始，不补暂停期间的任务。
- 同一原线程串行，项目写入沿用项目锁；最多两个自动化同时执行。等待审批不会自动批准。忙碌或目标暂不可用会显示排队原因。
- 重启时已开始但结果未知的轮次显示“结果待确认”，不自动重发模型。核实原线程实际结果后选择“确认已完成”或“忽略本次”；确需重新执行时明确点击立即运行。已失败轮次可明确重试。
- 结果留在原会话并带“自动化”标记，执行记录可返回原对话。应用内未读提示可选择每次通知或仅变化／失败；伙伴必须通过 report 明确核实无变化，才静默；未知不会当成无变化。当前不新增 Windows 系统通知。

## 和伙伴说一句话创建

例如：“每天十点检查这个已授权目录，整理新增文件，并向我汇报，请创建自动化。”伙伴可用 `asterium_automation` 建立任务。发起会话为完整权限时直接保存；其他可写模式显示星丛确认框，核对名称、内容、时间、时区和启用状态后保存，取消则不保存。工具身份固定为当前伙伴，不能操作别人的任务。

完整权限下，伙伴创建、修改、暂停、恢复和删除自己的自动化都不再弹确认。普通与自动审批模式保留确认，只读／Plan 仍禁止修改；自动运行中仍禁止递归管理任务。权限由 Main 从发起会话读取，工具参数不能指定；外部 MCP 没有可信会话权限时保留确认。需要确认时，窗口随主题切换，默认聚焦取消；Escape、关闭和遮罩点击均取消，刷新后可重新读取待确认内容。取消原运行或退出应用会拒绝其待确认请求。

自动执行中只能读取本人的任务、报告本次变化；禁止自动创建、修改或串联新自动化。网页、文件内容、其他伙伴发来的要求不能替代用户授权。外部管理需在伙伴设置的“群聊 MCP 接入”中勾选独立开关并保存；默认关闭，撤销凭据或关闭开关后失效。

## 需要用户完成的真实验收

自动验收使用隔离数据和模拟服务，没有调用你的 API、Claude 或 CyberBoss。请退出旧版星丛，再打开本次交付包；使用现有正常会话，不在聊天中提供 Key。

1. **本地伙伴本地原线程**：进入已有本地伙伴对话，新建一个两三分钟后的“一次”任务：“仅回复自动化验收完成，不修改文件”。到时确认回复出现在同一对话，没新建线程，执行记录为完成。若本地 CLI 需登录，先按原来方式恢复登录。
2. **关闭后的补执行**：再建未来几分钟的一次任务，关闭星丛，过时后打开。确认只补一次；再重启不重复。每天十点的补跑可使用已经存在的任务在当天十点后启动验证，不要通过下午新建任务测试。
3. **保存／审批／取消**：普通审批模式下让本地伙伴提议一个每日任务，检查弹窗；取消一次后确认没保存，再明确确认保存。完整权限下应直接保存计划，无需点击同意。手动审批模式下用专门测试目录验证实际写入仍需审批，拒绝后不会写入；取消本次与暂停计划分别生效。避免用真实资料做第一次整理测试。
4. **API 伙伴**：在已配置并由你选定的测试连接，用相同“只回复”任务验收；不需要重新发送 Key。切换至别页或退出后重启，确认回复仍保留。
5. **群聊**：从已有群聊选择目标伙伴，确认只触发所选伙伴，系统触发和回复区分，原审批卡可操作，原单聊没有串入群结果。
6. **外部伙伴**：暂不测试真实自动运行。先由单独授权的 CyberBoss 任务实现 Adapter 并完成专用合同验收，再接通星丛。参考 SDK 模拟通过不代表外部伙伴已接通。

任何结果待确认都先检查原线程，避免重复移动／删除文件。自动化数据位于星丛用户数据目录中的 automations.v1.json，包含任务内容和结果；勿把私人运行记录提交到仓库。SDK 的真实验收配置也不要填写真实密钥到示例文件。
