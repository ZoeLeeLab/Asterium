## 修复范围

- 头像：原先头像框为正圆，但竖图作为网格子项时实际图片框会溢出。将图片定位在既定头像框内，等比居中 cover 裁切；原图片数据和上传逻辑不变，不新增手动拖拽裁切界面。此为显示修复，不改变能力或权限定义，工作室能力条目无需重新定义。
- 记忆兜底：保留 DeepSeek 官方旧配置，增加现有 Chat Completions、Responses、Anthropic Messages、Gemini 适配器选择与手动模型 ID。处理各协议工具结束标记及请求间的原生状态；Anthropic 使用既有输出上限默认值。
- 凭据：继续独立保存，不继承伙伴 Key。变更服务必须提供新 Key 或明确移除旧 Key；列表读取和执行使用与配置匹配的凭据快照。新 Key 先写入独立引用，再原子保存对应配置，配置写入失败不能把新 Key 绑定到旧服务。旧格式缺少 credentialRef 时按原引用读取，不启动迁移或读取日常真实配置。
- 兜底仍只执行检索、读取证据和整理提案校验。未提供工具调用、返回无效提案或中途取消时，不写入未校验结果；现有四次模型请求上限、闲置扫描、重试和逐伙伴开关保持原规则。协议变更可中止正在进行的旧整理。

## 核验记录

所有资料为独占自动测试目录中的合成数据，API 响应由注入 fetcher 生成，无真实网络模型、账户、私人凭据或已有原生线程。浏览器使用独立 headless 实例和随机本机 Vite 端口。

- 专项初轮：4 文件、35 项通过；后续增加配置写入失败、旧格式 Key 和协议切换取消用例，纳入最终回归。
- 浏览器：先恢复旧图片布局复现竖图溢出，再验证修复。侧栏图片框从 34×102 恢复为 34×34，项目摘要从 46×138 恢复为 46×46；图片原始 120×360 数据保持不变。四项检查通过，人工查看截图符合居中等比裁切。
- 初次浏览器断言错误地把“图片溢出”当成“外框增高”，失败后改为核验实际图片框。
- lint 首轮发现新浏览器脚本中未限定的浏览器全局名，改成 globalThis 后通过。类型检查发现存储泛型推断过窄，补显式类型后通过。
- 全套初轮在与 typecheck/lint 同时运行时，能力词典回归超过其既定 5 秒期限。四 worker 重跑及单 worker 独跑仍分别约 5.86、5.12 秒，故不能仅归因于并行检查。
- 最终 `npx vitest run --maxWorkers=4 --testTimeout=15000`：213 文件、1688 项通过、0 失败、2 个既有 TODO，65.14 秒。词典测试三项全执行，其中真实词典检查约 5.96 秒；15 秒仅为本次运行参数，没有修改仓库默认 5 秒、校验规则或断言。默认时限下的 Windows 词典检查仍有超时限制，本轮不扩展为检查器性能重构。
- `npm run check:capabilities`：16 条全部通过；类型检查、lint 和浏览器四项检查通过。补充用例覆盖保存后采用规范化地址、再以对应已保存 Key 拉取列表。
