# 外观自定义

在设置 → 外观中选择基础主题，再按需覆盖外观。自定义设置跟随用户，而非跟随某个伙伴；单聊和群聊共用。切换基础主题保留覆盖，点击“恢复默认”清除所有外观覆盖并恢复星海及默认字体字号。聊天内容不会改变。

## 消息样式

- 气泡：保留原有左右对话，可以修改双方气泡颜色、不透明度和圆角。
- 简洁：去掉消息气泡，自己的发言与头像在右、伙伴在左，保留名字、正文和操作按钮；原有工具、引用、附件与审批继续保留。为保证背景图上可读，默认使用主题阅读底色；可以在“聊天画布”中覆盖。

## 深浅色覆盖

背景、三栏、画布、卡片与气泡分浅色、深色两套保存。当前界面显示哪种模式，就编辑哪一套；可以先在上方固定选择浅色／深色，完成后再切回随系统。

背景接受 PNG、JPEG、WebP，单张最多 10 MB，最大 16000px 边长／3200 万像素。选择文件后，复制图片字节到星丛用户数据内的 IndexedDB，以内容 SHA-256 标识；移动原文件不影响已导入背景。没有新增任意文件读取接口。可以设置完整显示／铺满、位置、模糊和遮罩；关闭“显示背景图”保留主题底色。恢复此模式的主题背景只重置当前模式。

左栏、中栏、右栏分别提供底色、不透明度和磨砂。聊天画布与右栏卡片是上面的另一个层级：三栏变透明但卡片仍有底色是正常的，可以继续在高级面板里调整。0% 表示背景完全透明，100% 表示不透明；文字、按钮、头像不随底色透明度变淡。不开启自定义时沿用主题默认。

恢复默认或移除背景引用不会立即删除旧图片，方便导入／导出失败后恢复。需要释放空间时点击“清理未使用的背景图片”，仅保留当前已保存设置引用的深浅两张图片。导出自己想保留的配置后再清理。

## 自定义 CSS

高级区输入后点击“应用 CSS”生效；输入中不会自动改变界面。停用会保留草稿。样式在基础主题与面板覆盖之后加入，仍遵循 CSS 的选择器优先级；必要时在精确选择器上使用 `!important`。支持媒体查询和深浅色规则。最多 64000 字符；使用浏览器 CSSOM 解析，不执行 JavaScript，不支持 `@import`、`url()`、`image-set()` 等资源加载，图片请使用背景导入。原应用 CSP 保持不变。

```css
/* 对方消息 */
.message-row:not(.message-row--mine) .message-bubble {
  border-radius: 18px !important;
}
/* 自己的消息 */
.message-row--mine .message-bubble {
  box-shadow: none !important;
}
/* 深色文字，与基础主题切换独立 */
:root[data-theme='dark'] {
  --text-strong: #f0eadc;
}
```

常用入口：

| 入口 | 范围 |
| --- | --- |
| `.message-row` / `.message-meta` | 单聊和群聊消息行／名字时间 |
| `.message-bubble` | 消息正文容器（简洁模式仍保留 DOM） |
| `.message-row--mine` | 自己的消息 |
| `.chat-left` / `.studio-left` | 单聊／工作室左栏 |
| `.center-stage` / `.studio-center` | 单聊／工作室中栏 |
| `.right-rail` | 两种页面的右栏 |
| `.message-canvas` / `.discussion-view` | 单聊／群聊画布 |
| `.side-section` / `.partner-quick-card` / `.studio-side-card` | 右栏卡片 |
| `:root[data-theme='light']` / `:root[data-theme='dark']` | 当前实际深浅模式 |
| `:root[data-color-theme='sea-letter']` | 某个基础主题 |
| `--text` / `--text-strong` / `--muted` | 常规／强调／次要文字颜色 |

这些是本次公开的样式入口，修改其语义时需同步更新本说明及桌面验收。其他内部 DOM 选择器可能随布局调整而变化。用户 CSS 可以隐藏元素，只应用自己理解的样式。

**紧急恢复：在星丛窗口按 Ctrl+Shift+F12。** Electron 在页面处理按键之前捕获它，不受 CSS 隐藏设置页影响。它停用 CSS、清空自定义背景／面板覆盖并恢复气泡模式，保留主题、显示模式、字号字体及 CSS 草稿。然后打开外观页。不会停止任务、删除图片、聊天或伙伴。仅在星丛窗口生效，不注册全系统快捷键。

## 分享配置

导出生成 `星丛外观.asterium-theme.json`，包含主题、字号字体、深浅色覆盖、CSS 和引用的两张图片，不含聊天、伙伴、文件路径或凭据。内置主题图片由程序提供，不重复打入配置。

导入最多 30 MB 的配置包，检查版本、图片类型／尺寸及 SHA-256 后，点击“导入并应用”。它替换当前外观；CSS 始终默认停用，审阅后自行应用。错误包不覆盖原偏好。导入不会安装字体，未安装字体沿用既有回退规则。
